# Kimi Web 入库核查

来源为2026-10-20的Kimi网页现场研究，包含用户完成正常登录后的中性项目、说明编辑、会话富文本、生成过渡、插件搜索与技能目录。新增到`platforms/web/kimi-web`，不覆盖`platforms/mobile/kimi`的Android历史研究，也不新增子模块。

原计划的设计规范、核心组件/状态、布局、通用交互/动效、可复用资源、独立参考/原版对照和不同业务切片已具备。机器入口有62项tokens、17类组件、7种布局、10组交互和7组动效；本次入库补齐了六类组件的D事件接口，没有改写原版运行结论。

ready仅表示包内supportedUses可实施。真实网络故障、后端取消/晚到结果、移动OS/软键盘、第三方授权和全部账号/后台分支仍未测。原版coverage保持相应partial；主要动效时间是B声明与D选择，未伪称逐帧实测。

公开版本通过显式依赖清单选择210个文件。完整原始DOM、登录QR图和完整REA记录保留私有原件与实际SHA；公开REA投影保留真实Evidence ID、动作、截图和限制。JSON去除研究项目/会话URL标识；不提交账号profile、私人历史、凭据或缓存。明细见来源的PUBLICATION_REVIEW.json与PUBLIC_MEMBERS.json。

公开资源含16个原始SVG、两张通用项目插画、字体栈和精选组件声明。上游品牌/资产使用权不因入库扩展；含水印原图有说明，也提供无品牌Folder SVG替代。

随库技能同步至`rea-design-transfer` 1.0.3，上游提交`57d4599caa08487ec87c72deab4e9969821381ae`；网页复制的AI任务同步“优先直接复用、按UI逻辑轻量增删功能和文案”。技能字节锁独立校验。

本轮为入库和消费者核查，不启动原App或新增A。来源已有首轮22项和登录后16项参考检查。总库44项测试、build与verify均通过；校验31902个来源文件、7份来源和6张已审缩略图。公开清单的210个文件与投影哈希已复核，未检出凭据或研究私有标识。

在`/rea-ui-library/`项目子路径实际打开构建后的目录，核对Kimi Web详情缩略图、四项配色、Segoe UI/Segoe UI Semibold/system-ui及复制AI入口，浏览器无错误。此检查是目录D验证，不是原版新A。Pages按现有工作流发布。
