# 当前三页图像复核

这是早期迭代记录；最终 accepted 结论见 [final/findings.md](final/findings.md)。

此记录对应 `differences.json` 的三个 `reviewReferenceSha256`。人工已看过三组并排、三组叠图和十组件派生裁剪，选定位置又以 Pillow 测量。未来参考图改变后，本文及原人工记录作为历史复核保留，不能自动当成新图结论。

Health 的大标题墨迹位置对应，摘要和未登录卡外接几何接近；最明显差异是 Hero 的平切环端、分享面缺少描边/阴影，以及饼干和计数下移。三摘要列内的字形/图标/箭头间距仍有差，空指标卡和底导航的字形/尺寸也未全对齐。

Mine 采用正确的五入口更新包，主要两列面位置对应。快捷入口文字比原版下移约14px，资料姓名下移4px；健康问诊面参考高187px、原版165px，使后一行下移。会员斜向底纹和多个运营文案排版是明确差异，不能称还原完成。

Settings 的按钮与开关橙色连通范围对应；地区、云服务、授权和通知标题的墨迹框也对应。返回箭头参考更大更黑；尾部 chevron 更细，按钮文字有数像素横向差。普通 roundRect 与 MIUI adaptive/smooth drawable 保留实现差异，不能因颜色和外接框相同断言数学曲线等同。

当前图只支持未登录、无设备/数据、中文浅色、fontScale 1 的这些页面状态。行为检查、深色对照、完整动画和真实登录状态均不由本图像复核证明。开关此帧是橙色开启；原版自定义控件 `checked=false` 不能推翻像素和描述中的开启状态。

可视入口是 `index.html`，全部原始/参考 REA ID、哈希、色块边界、未确认文字/图标候选位移、逐项差异和未知都在 `report.json`。组件裁剪依据在 `component-crops.json`，原 PNG 保持不变。
