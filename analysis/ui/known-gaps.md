本包可以直接用于新项目的核心风格与交互实现，但下面的边界仍需保留。

| 项目 | 已有依据 | 尚未证明 / 实施处理 |
| --- | --- | --- |
| 核心页面 | 原生代码、RN AST、资源、19张可用原界面截图 | 不等于整个 App 的所有页面和权限/账户/设备组合 |
| 热更新 | 新旧 mine 版本、哈希、源码和截图已闭环；common字节一致 | 新 sport 11.222.10 只保存与运行取证，未重做全量静态语义；不可默认所有旧规则都未改变 |
| 登录 | 控件层级、SECURE窗口、认证广播和取消后页面可见 | 账号页像素受保护，3个黑帧已排除；未输入账号或验证登录后流程 |
| 已绑定设备 | 页面结构与能力筛选代码、空设备实屏 | 未连接外设，实际设备能力卡、配对/同步成功/失败组合未遍历 |
| 有真实数据的图表 | 模块、绘制/布局入口与空态 | 未填造健康记录，复杂图表/真实数据可视化未逐项运行校准 |
| 字体 | 字体文件元数据、字重/字号角色、cmap探针、模拟器字体配置 | MiSansLatin不是完整中文字库；未核实小米实机OEM的确切字形，不把模拟器字体说成完整MiSans |
| 圆角与材料 | MIUI adaptive/smooth drawable、RN半径/模糊参数 | CSS示例是可替换的跨平台近似，尚未建立全组件逐像素相等 |
| 动效 | 对应RN组件参数、原始滚动录像、源码调用证据 | 并非每个效果都做了逐帧测量；不能把某个弹簧或300ms节流全局化 |
| 尺寸与适配 | 基线约392.73dp宽，fontScale1与1.3样例；折叠/平板代码分支 | 360/430逻辑宽度、真实折叠屏和系统大字的全部状态未在原APK遍历；研究台390px检查仅属于重建预览 |
| 跨平台 | Android运行证据、RN部分iOS代码分支、Web重建研究台 | iOS/桌面原App未运行验证；迁移时保留设计角色并单独说明平台适配，不能把手机布局或Android动效当成通用桌面规范 |
| 状态规则 | 多个实际返回/重复点/隐私/空态检查及代码条件 | 其他页面的编辑取消、重试、权限永久拒绝等需按相应源逻辑实现并继续验证 |
| 软件逻辑 | 重点是影响体验的导航、状态、刷新、前置资源、反馈和权限流程 | 后台协议正确性、医学算法与服务端业务并非本设计规范包的完成标准 |

读取规则：`runtime-observed` 为具体运行状态，`code/resource-observed` 为包内事实，`inferred` 为推导，`adaptation` 为新项目实施建议。未知值应保留可配置接口或明确默认方案，不能补成“原 App 精确值”。

研究台和 TypeScript 契约是研究提炼的独立参考实现；原 APK 截图与其重建演示已分开标识。参考项目的最终验收应依据 [acceptance-checklist.md](acceptance-checklist.md)，并公开有意改变与未解决的偏差。
