本清单供下一位实现 Agent 逐项验收。未实测项目使用 `未验证`，不要默认勾选，也不要用主观相似度代替具体偏差。

**输入和基线**

- [ ] 固定本包版本、参考截图状态、平台/API、分辨率、density、fontScale、语言和主题。
- [ ] 有热更新时另固定实际 JS/UI bundle 版本与哈希，截图不跨版本误比，运行包与内置包差异已解释。
- [ ] 页面采用 native 或 RN 对应基线，未混入旧版兼容 XML。
- [ ] 主题、字体文件及中西文字形回退已记录；缺字/字体替换导致的偏差可追踪。

**视觉**

- [ ] 背景/卡片/浮层/分隔/文字的语义角色和明暗覆盖一致。
- [ ] 标题、正文、说明、数据值/单位的字号、字重、行高与基线一致。
- [ ] 外边距、卡片间距、对齐、触控区、导航高度与真实来源一致。
- [ ] 按下/选择/禁用/加载/错误/空态的样式均实现；透明度按 ARGB 正确换算。
- [ ] 自适应圆角、模糊、阴影等不支持项明确近似，未宣称完全相同。
- [ ] 同尺寸同状态截图做并排或叠图，记录具体差异；不捏造“99%相似”。

**交互和状态**

- [ ] 主导航选择/重复选择、子标签/分页、返回和根退出符合页面契约。
- [ ] 切页和返回后保留必要对象、日期、滚动/编辑上下文；重置条件明确。
- [ ] 重复点击、过渡锁、组件节流各自符合规则，未对所有按钮统一加延迟。
- [ ] 刷新、初次加载、保留旧数据、空数据、请求失败、离线和重试分别验证。
- [ ] 无权限/未登录/前置条件不足时提供对应反馈，不把禁用视觉等同于无反馈。
- [ ] 模态背景、取消/确认、点击遮罩/系统返回行为分别检查。
- [ ] 前置资源准备有进度、成功续接与失败恢复；不会遗失用户意图。

**动效、系统适配和可访问性**

- [ ] 动效参数使用相应组件来源，未把一个 RN Navigator 的弹簧推广到全 App。
- [ ] 窄屏、较大文字、横屏/平板适用分支、软键盘和安全区检查。
- [ ] 长标题、长数字、中文/英文混排、缺图和慢加载均无截断或重叠。
- [ ] 目标平台支持的焦点顺序、语义标签、触控区域、对比度和减少动效设置已验证；新增适配标为实施规则。

**证据与迁移**

- [ ] 原 APK 截图、模拟/演示数据和重建预览明确分开。
- [ ] 每个关键规则能追到源码/资源/REA Evidence 或运行记录。
- [ ] 新业务只替换业务层内容；保留设计层级和交互过程，并说明有意改变的部分。
- [ ] known-gaps.md 没有被“完成”标签掩盖；需要账户、外设或特定 OEM 的分支仍有记录。
