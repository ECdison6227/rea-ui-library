## Synthetic clipboard helper boundary

`.ClipboardFixtureActivity` is an explicitly requested separate D research helper for reproducible self-created input, including Arabic. The exported Activity accepts only `fixtureBase64`; decoded text must start with `Research Run03` and contain at most 2,000 Unicode code points. It waits for foreground window focus, performs a single guest Android plain-text clipboard write, emits content-free length/SHA/status metadata, and finishes. No host/guest clipboard read, original-package data access, account service or network capability is present. The script uses a separate temporary task and verifies return to the previous activity. The initial author did not execute it; retained controller `evidence/reference/run03-20261016/clipboard-events` now record actual synthetic-write attempts. Destination paste is a separate original-product observation, not inferred from a helper status or these native-screen checks. No clipboard value is restored automatically because doing so would require reading previous clipboard data, which this helper is explicitly prohibited from doing.
