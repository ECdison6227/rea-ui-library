# 交付与本机保留范围

研究库用于本地审阅，未公开发布。原APK、AVD磁盘、账号登录状态、设备缓存和`.runtime/`私有调试资料不打包。

Run03 使用 [源场景精确允许名单](run03-safe-scenes.json)、[逐帧审核](run03-evidence-audit.json)、[D 独立名单](native-reference-safe-scenes.json) 和 [motion 精确文件名单](run03-motion-safe-files.json)。PNG、UIA、capture 必须整套逐字节匹配；新、未审、变化或明确排除的源/D文件默认不分发。源场景共275套，257套安全，18套排除；其中17套涉及身份/私人历史等隐私，253为缺UIA的不完整采集，不能把所有排除都称为私人内容。

本轮“Generate image → Save to album”的自建聊天导出图含账号身份和QR，原图仅本机私有位置留存，不放资产目录或ZIP。分享面板已取消，没有向外部应用或联系人送达。一次误入既有私人会话已记录在 [incidents](../evidence/runtime/run03-20261016/incidents.json)，未在该会话输入或提交，相关原件整套排除；不声称本轮从未进入私人内容。

Motion视频及逐帧PNG是单独看图复核后的精确集合，仅允许名单内文件；中间HTML、浏览器缓存与未知录屏不分发。原生工程只允许最终 `reference/build/native-reference.apk` 和 build-result；中间classes/DEX/JAR/APK、签名私钥、运行锁和本机日志均排除。

本机完整验证仍要求原APK和被排除原件；消费者验证仅要求明确公开字节，不依赖本机AVD或私人文件。最终实际ZIP另外检查路径、解压成员SHA和未知/排除文件，见 [验证模式](run03-verification-modes.md)。工作区中存在本机原件不代表它们已进交付包。

第二轮`r02-18-post-login-guide`与`r02-19-prompt-ready`原图包含登录后问候身份，只在本机原始证据中保留；本轮独立画面预览不读取/不内嵌它们，交付ZIP排除对应场景目录。session只保留这两个被排除场景的来源记录与哈希，明确作为未随包提供的本机证据，不依靠它们证明公开的关键功能结果。

其余导出的运行画面逐张核对，登录、手机号与验证码页面未采集。凭据值没有写入研究文件；验证脚本只记录扫描结果和命中数，不记录被扫描的凭据值。账号登录资料只在用户协助登录的本机AVD内存在，不是可复用设计资产。

素材原件继续保留各自来源和用途边界。研究留存不等于允许公开再分发第三方品牌、字体或图片；本轮没有执行公开发布。
