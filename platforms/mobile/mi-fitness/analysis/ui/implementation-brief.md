实现时先建立 `raw → semantic → component` 三层 token 和平台适配。对新业务先做一个概览页、一个详情/记录页和一个设置/编辑页，完成有值、空、加载、错误、受限、禁用/按下/选中等适用状态，随后推广到其他页面。

字体不能简化为“全 App MiSans”：mipro系统族、随包MiSansLatin、CJK回退和数字字体分别处理。Android ARGB的alpha、dp/sp、RN逻辑单位、NativeBase token、截图像素均保留来源。布局矩形高度不是字号；资源名中的百分比也不一定等于真实alpha。

图标的视觉边界与触控区域分开。已观察的局部触控尺寸不应被冒写成统一44/48的原包规范；新平台增加hitSlop或无障碍适配属于实施规则，需要记录。全业务迁移示例和替换准则见 [migration-guide.md](migration-guide.md)。
