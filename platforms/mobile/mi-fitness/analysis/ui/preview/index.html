事件记录

    可追溯资源与代码值

    主题与语义 Token

    原生 Android 八位色是 #AARRGGBB；CSS 与 RN 这里使用 #RRGGBBAA。先转换 alpha，再用于网页。RN 的逻辑数值和 NativeBase token 解析不等于物理像素。

    文字角色 / 字体局限

    中文回退与 Latin 数字分别检查

    包内 MiSansLatin 字体可本地预览；探针已确认不含“一 / 健 / 康”。中文使用当前系统可用字体回退，不能据此判断原手机字形。页面大标题的 mipro-light 没有在这里用不存在的本地字体伪装。

    层级样本

    实际文件与字重

    FontMedium 原生样式请求 mipro-regular + bold；不能仅按名字映射成 500。RN 设置行的 bold 优先于同时传入的 fontWeight=500。默认行高没有统一证据，样本行高仅为网页排版选择。

    原生按钮候选样式

    宿主样式声明高 46.659973dp、15sp。原版 AdaptRoundButtonDrawable 为平滑自适应形状；此处 CSS r16 只是近似。禁用时单独改变文字，未用整个控件统一 opacity。

    原生按钮来源与边界

    功能行：视觉禁用与点击分开

    父类 allowClickWhenDisabled 默认 false，开启时 disabled 状态的 ACTION_UP 仍触发 performClick。setDefaultEnable 另将前导图标 alpha 降为 .25。网页用 aria-disabled 表达此种可解释禁用态。

    如何继续复刻

    1. 确定业务名词、导航层级与公开 / 登录操作。
    2. 沿用语义层级，分别选 RN 或原生组件来源。
    3. 补全初次加载、刷新、空态、失败、离线和禁用。
    4. 用取证图片校准可见状态；用交互取证校准时序。

    字体回退、safe area、网页动画曲线、通用线条图标均是适配项。研究台不修改原规范，也不向 App 服务发送请求。
