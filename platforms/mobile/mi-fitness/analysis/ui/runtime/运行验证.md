**已观察的交互**

| 操作 | 本次实际结果 |
| --- | --- |
| 欢迎页立即体验 | 进入用户须知 |
| 未勾协议直接同意 | 弹出底部二次确认，取消与同意并继续并列 |
| 在二次确认按系统返回 | 对话框保持；前后节点数据一致 |
| 同意并继续 | 进入地区页，默认中国大陆；地区列表返回后选择保持 |
| 完成地区流程 | 进入健康首页，未登录仍可见总览和空健康卡 |
| 运动首页 | RN 首次挂载有延迟，最终可见分类入口与无运动记录状态 |
| 设备/我的期间出现账号页 | 存在后台认证广播链；取消后仍可浏览设备空态和我的。不可写成 Tab 的强制未登录拦截 |
| 重复点当前“我的”Tab | 保持滚动位置，前后全部节点数据一致 |
| 从滚动后的我的进入设置再普通返回 | “App 设置”行的滚动锚点位置保持 |
| 设置中切系统夜间模式再返回 | 本次配置变化重建后落到健康；它不代表普通返回的通用规则 |
| 运动记录“全部” | 打开含周/月/年/总、月份条与暂无数据的记录页；类型下拉本次只有“所有运动” |
| 根页面系统返回 | WindowManager 焦点回到 NexusLauncher；重新启动进入 MainActivity，无需再走欢迎页 |
| 系统 font_scale=1.3 | 已保存样例；局部度量变化不等于所有文字按1.3倍等比变化，也不代表所有大字状态已验收 |

动作记录在 [events](events/)，新鲜 UIAutomator 快照在 [hierarchy](hierarchy/)，比较结果在 [interaction-checks.json](interaction-checks.json)。一次过渡中 hierarchy 返回空根，早期共享文件读到了上一页；那份记录已丢弃并保存失败说明。当前驱动为每个状态使用独立路径，并拒绝失败 dump，避免沿用旧页面。

| 模块 | APK 内置 | 后续实际加载 |
| --- | --- | --- |
| common | 11.183.36 | 同版本，bundle 字节 SHA-256 完全相同 |

因此不能把旧浅色四项和新深色五项的变化解释为主题规则。[runtime-rn-crosscheck.md](../runtime-rn-crosscheck.md) 说明了闭环证据，运行包与配置保留在 [active-bundles](active-bundles/)。确认版本后已将模拟器设为飞行模式冻结后续下载。仅在本项目新建的 userdebug 模拟器上启用了 adbd root，以读取目标 App 的 JS 缓存和配置；未读取账号数据或数据库。

**颜色、尺寸与字体的使用方法**

[pixel-observations.json](pixel-observations.json) 是对原始 PNG 的只读像素采样：例如设置主按钮日 #FF612E / 夜 #F04D18，与资源一致；主导航面日 #FFFFFF / 夜 #242424；RN 页面面日 #F6F7F9 / 夜 #000000。采样点只说明该点，不会自动成为整个 App 的统一底色。

[measurements.json](measurements.json) 给出 13 个状态的控件边界及基于440dpi的逻辑尺寸换算。文本矩形是视图/行盒，不是字号；字号和字重仍以资源/代码为依据。层级中倒置或屏幕外的矩形已排除。自定义控件的 checked=false 也不能单独证明视觉开关关闭，本次设置页实际有橙色开启开关与“当前已开启”描述。
