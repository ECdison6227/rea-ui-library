# 拾页：跨业务可运行 D 参考

这是汽水设计语言向资料清单场景的可操作Web适配。复用深表面、薄荷决策层、绿色主动作、内容优先、草稿/保存取消和显式反馈关系。它沿用本研究的D目标profile；不是原版Android运行，也不替代原生ConsentPanel对照。

直接打开[index.html](index.html)，无依赖、网络、账号、存储或后端。可新建/编辑资料、检查空值/长度错误、放弃草稿、取消/确认删除、分类搜索、失败重试及应用字号。资料只保存在本次页面内存；刷新重置，60字符限制与业务语义均为D。

文字使用system UI；字号/行高、触控48px、窄屏布局、弹层220ms与减少动画0ms均为Web目标选择。CSS px不冒充Android dp/sp。原生参考0.1.0和已知字形/渐隐差异保持原样。

本轮浏览器验证及视口条件见[验证记录](../../evidence/completion-20261020/portable-validation.json)。键盘Tab/Escape/Enter、焦点包含/恢复、320px、200%文字、长标题、错误重试与减少动画分开记录。CDP可访问性角色检查不等同真实TalkBack/NVDA语音测试。
