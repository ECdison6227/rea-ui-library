# 将规范用于手机控制器

先读design-package.json的readiness、source和模块，不混用旧Web Hark与本版Android数值。原版未知和目标D选择随实现保留。

用户已于2026-10-22授权在原生运行受限时采用库内Web元素。现有Web研究包含390×844手机视口实测；可直接使用独立 [Web→手机适配](WEB_TO_MOBILE.md) 和 `reference/web-mobile.html`。这是有来源的另一条目标实现路线，不能据此把原生15/18sp改写成Web15/19px，或把Web三段导航当作原生导航。

| 落点 | 复用/适配 | 目标职责 |
| --- | --- | --- |
| 语义配色 | 直接复用JSON角色、薄包装主题 | 断连/失败/撤销有文本和语义，不只颜色 |
| 排版 | 保留sp/weight；许可允许才接原字体 | fallback下校准换行/大字，不把CSSpx当物理像素 |
| 发送触区 | 48dp高度与compact分支B | 扫码按钮同样有足够触区，实际连接目标相机流程 |
| 内容卡 | 复用source/title/结构化内容/主次动作 | 事实、选择、备注、迁移/聚焦仍走Vivic协议 |
| 输入 | 复用D reducer后接实际API | 请求ID、防重复、断连/超时/重连/撤销另验收 |
| sheet | 单决策与焦点恢复；Android原生返回栈 | 设备/配对确认/模型选择都用目标真实数据 |
| 背景/动效 | 语义可复用，参考渐变/blur为D | 低端机、减少动画、相机预览有明确降级 |

功能完成后建议走一条小路径：打开手机→扫码→桌面确认→连接状态→发文字→卡片出现→聚焦/移动→断连重连→撤销设备。这是目标需求，**不是恢复出的Hark连接协议或其真实功能声明**。品牌、二维码、安全短码、远程访问与服务器配置保留Vivic身份。

参考仅验证合成任务与本地输入，没有摄像头扫码，不表示Relay/决策模型/多窗口接线完成。目标新增控件必须有真实行为，失败/取消/返回/数据保留逐项验证。

先检查目标现有字体/图标/组件。许可及平台适用时直接复用；当前原字体不分发，不从私有研究目录自动复制到公开App。优先目标已有Lucide并记录映射，不为风格重画整套图标。参考的基础图形为D。
