# Muse 公开首页设计规范

本规范提取 **2026-10-21 采集的 Muse 公开首页**。用户明确限定「就这一个界面」「不用 login」。范围包含这张页面自己的首屏和纵向内容，不进入账号、工作区或其他业务页。

机器入口：[design-package.json](design-package.json)。源部署标识、版本和真实哈希见入口及 [证据索引](evidence/index.json)。

## 证据和条件

A 表示原页面实际观察；B 表示当前原页加载的 CSS、字体、脚本声明；C 表示推断；D 表示本包独立实现或迁移决定。组件名、语义 token 别名、参考交互和阅读示例都是消费者接口，不是原应用 API。

原始 REA Evidence ID：`ev_ba755d0136d0b9d07848fb4e5fb07a553dff4a6ea6c47fcebc54b1e89144ceeb`，原件见 [rea-baseline.bundle.json](evidence/rea-baseline.bundle.json)。该操作返回耗时而非绝对快门时间，索引保留由之前的 HTTP 文件与后续导出事件限定的区间；后续截图有实际起止时间。截图、DOM、样式均顺序采集，不是原子快照。

代表环境为 Windows、Chromium 155.0.8059.40、英文、浅色、DPR 1；画布为1440×1000、768×1024、390×844 CSS px。桌面上下文 resize 的手机样本与新建手机上下文有文字栅格化/加载状态差异，原因未完整归因；原件都保留，最终手机配对选择字体 ready 且 Continue 已启用的新建上下文。

## 视觉组织

设计使用大面积留白、近黑文字和蓝色主动作形成层级。圆形头像与立体小物件承担品牌性，主要容器很少堆叠卡片边框。首屏约束输入区宽度，下方使用宽幅交替底色图文。

迁移应保留品牌→双行标题→窄输入区的居中轴线、正文与辅助文字对比、方形插画与正文尺度关系、主动作与信息内容的层级。品牌词、头像、图片内容和业务动作通过插槽替换。上述风格判断属于 C 视觉归纳。

## 字体和文字角色

原页使用 **Optimistic AI 变量字体**。保留了 [原字体文件](assets/source/_next/static/media/OptimisticAI_VF_Optimized-s.p.1qcbydubu9isy.woff2)、[font-face声明](assets/source/_next/static/chunks/2oajnzr9qmzq3.css) 和 [CDP字体绑定](evidence/raw/font-bindings.json)。标题、输入和按钮的 custom-font 与 PostScript 名称已实测；并非仅凭 family 字段推断。

## 页面布局和响应式

原页使用独立100dvh滚动容器。首轮操作window未移动页面，相关原件保留但不作为滚动覆盖。后续显式操作 `[class~="group/scroller"]` 并保存实际scrollTop。

页面顺序：首屏→介绍媒体→六组图文→导览封面→三条信息链接→收尾→页脚。1440px下，两列各632px、缝64px、上下各56px，典型图文行高744px；中宽缝48px；手机单列缝16px，描述缩为16/22。

媒体宽82%、最大116.622222vh。标题容器最大768px，内边距16px。媒体语义圆角24px；支持 `corner-shape:squircle` 时使用48px CSS radius，否则回退24px。信息链接组合在大屏采用12列：标题5列、列表7列、gap48px。两层容器导致的额外边距是源结构的一部分。

## 交互

原“Learn more”以.8秒滚到介绍区并扣除Header偏移，源码声明完成后交付焦点，手动滚动可中断。Header按钮的源处理器回页首并执行输入回调；没有把它当成登录后导航实测。

头像悬停播放working视频、离开暂停并淡出，idle视频可继续到末尾。采样已观察currentTime推进和标题更换。触控.4秒长按来自声明，未用真实触控设备验证。

参考Continue属于D：保留草稿并滚动，无账号请求或持久化。阅读收藏把它映射为本地筛选，含有结果/空结果状态。外部信息、法律和导览链接仅在用户点击时访问。参考不会自动发送外部请求。

| 动效 | 源参数 | 实现与证据边界 |

## 资产和直接复用

原件在 [assets/source](assets/source/)，用途/哈希在 [manifest](assets/manifest.json)。字体、Muse标志、六张插画、头像视频与导览封面直接使用。Meta原SVG有大画布留白，源页通过 `mask-size:auto 300%` 呈现字标，参考沿用。

源CSS/JS仅供证据分析，参考不执行它们。可复用结构在 [components.js](reference/components.js)，源文案/图片/短句在 [source-content.js](reference/source-content.js)。独立实现和原件授权分开，本次按用户授权审查后公开入库，记录见 integration/README.md；不因此授予额外资产许可。
